# 球面双摆模式(平面/球面切换)— 设计文档

- 日期:2026-09-12
- 状态:已获用户批准(路线二:笛卡尔坐标 + 约束积分器;平面/球面共存)
- 前置:`2026-09-12-double-pendulum-teaching-upgrade-design.md`(已完成并验证,提交 d6fa7ea)

## 1. 目标

在现有平面双摆模拟器中并列加入**球面双摆**(真实三维运动),面板一键切换。平面物理与验证套件保持原样回归。

## 2. 物理核心(新文件 spherical.js)

- **状态**:两摆锤笛卡尔位置+速度(12 维,悬挂点为原点,y 向上,重力沿 −y);
- **约束**:‖p₁‖=L₁,‖p₂−p₁‖=L₂(取半式 c=½(‖·‖²−L²) 以简化雅可比);
- **积分器 RATTLE**(辛、保约束):半步踢(重力)→ 漂移 → 位置投影(2×2 牛顿迭代,至 |c|<1e-13,至多 8 次)→ 半步踢 → 速度投影(线性,一次求解)。投影中位置修正同步以 μ/dt 修正速度;
- **初值映射**:dir(θ,φ) = (sinθcosφ, −cosθ, sinθsinφ)。p₁ = L₁·dir(θ₁,φ₁);p₂ = p₁ + L₂·dir(θ₂,φ₂)(相对第一杆!)。v = L·(θ̇·∂dir/∂θ + φ̇·sinθ·eφ),其中 eφ=(−sinφ,0,cosφ) 为单位方位基。**φ=0、ωφ=0 时与平面双摆逐点重合**;
- **反解**(显示/对比模式用):θ=atan2(‖(x,z)‖,−y),φ=atan2(z,x);角速度由 v 在 eθ/eφ 基上投影,ωφ = (v·eφ)/(L·sinθ),sinθ<1e-8 时取 0(极点退化保护);
- **能量**:T = ½m₁|v₁|²+½m₂|v₂|²,V = m₁G·y₁+m₂G·y₂。

## 3. UI 与交互

- "摆参数"区顶部**物理模式下拉**(平面[默认]/球面);切换 → 暂停、重建两摆(销毁旧 three.js 对象)、按滑条初值重建状态、清轨迹;
- 球面专属滑条(方位角 φ₁/φ₂,角速度 ωφ₁/ωφ₂)置于"初始条件"区 `.spherical-only` 容器,平面模式隐藏;
- 初值滑条改动统一语义:更新 params → 暂停态下按滑条整体重建状态(两模式一致)→ 清轨迹 → B 跟随;
- 对比模式:施加变量下拉按模式重建(球面追加 φ/ωφ),δ 单位规则不变;球面下 B 经"角度初值 + δ → 重建状态"同步;
- 轨迹缓冲增加 z 分量(球面轨迹呈空间缠绕);实时数据显示:球面下 θ 读数由状态反解、角速度读数为极向角速度、能量切球面公式。

## 4. 验证(tests/validate_spherical.mjs)

1. **平衡态**:全零角初值 → p₁=(0,−L₁,0)、p₂=(0,−(L₁+L₂),0);100 步后约束 |c|<1e-12、速度为零、能量不变;
2. **约束残差**:混沌初值 60 秒(dt=0.002)后 |c₁|、|c₂| < 1e-9;
3. **能量守恒**:同上 60 秒相对漂移 < 1e-6(RATTLE 辛格式);
4. **平面极限**:L₂=0.001(第二臂近似并入)、小角度释放,θ₁ 周期 ≈ 2π√(L₁/g) 误差 <2%,且全程 |z|<1e-9;
5. **非平面性**:θ₁=1 rad、ωφ₁=2 rad/s,5 秒内 max|z₁| > 0.05(抓方位角映射符号错)。

约束系统不做逐点 dE/dt 检验,由约束残差 + 能量守恒兜底。
