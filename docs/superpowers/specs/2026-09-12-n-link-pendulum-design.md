# 多杆链式双摆(N 杆,1–8)— 设计文档

- 日期:2026-09-12
- 状态:已获用户批准(1–8 杆;每杆一组动态滑条;全部锤显示轨迹)
- 前置:平面/球面双模式已完成(提交 9175e40)

## 1. 目标

两套物理(平面/球面)从固定 2 杆泛化为 **N 杆链(1–8)**,杆数运行时可调;每杆参数(杆长/质量/初值)独立可调。

## 2. 平面物理(physics.js 重写为通式)

状态:{theta: number[N], omega: number[N]}。

链式 N 杆封闭形式(Euler–Lagrange):
- β_ij = Lᵢ·Lⱼ·Σ_{k≥max(i,j)} m_k
- M_ij = β_ij·cos(θᵢ−θⱼ);M α = −(c + g_vec)
- c_i = Σⱼ β_ij·sin(θᵢ−θⱼ)·ωⱼ²(科氏/离心)
- g_i = G·sinθᵢ·Lᵢ·Σ_{k≥i} m_k(重力矩)
- N=2 时与原专用方程代数等价(回归测试把关);N=1 退化为单摆。
- totalEnergy:T = ½Σᵢⱼ M_ij ωᵢωⱼ,V = −G·Σᵢ (Σ_{k≥i} m_k)·Lᵢ·cosθᵢ。

## 3. 球面物理(spherical.js 参数化)

- 状态:{p: [x,y,z]×N, v: [x,y,z]×N}(悬挂点为 p₀ ≡ 原点、v₀ ≡ 0);
- 约束 c_k = ½(|p_k−p_{k−1}|²−L_k²);J、A = J M⁻¹ Jᵀ 为**三对角**(相邻约束共享一锤),γ_k = |v_k−v_{k−1}|²;
- 加速度:solve Aλ = J M⁻¹F + γ(γ₂…=0,均匀重力),a_k = (0,−G,0) − (λ_k d_k − λ_{k+1} d_{k+1})/m_k;N×N dense 高斯消元(N≤8,开销可忽略);
- RK4 + 每步微幅稳定化(位置牛顿投影 + 去径向速度),结构不变;
- 角度映射逐杆累积:p_k = p_{k−1} + L_k·dir(θ_k,φ_k),v_k = v_{k−1} + L_k(ωθ·eθ + ωφ·sinθ·eφ)。

## 4. UI(script.js 动态生成 + index.html 骨架化)

- **杆数滑条(1–8,默认 2)**置于"摆参数"顶部;变更 → 参数数组伸缩(新杆默认 L=1、m=1、θ=90°、φ=0、角速度 0)→ 重建面板与两摆;
- **每杆动态滑条组**(两列网格小卡片"杆 i"):摆参数区 L_i/m_i;初始条件区 θ_i/ω_i + 球面专属 φ_i/ωφ_i(模式切换时整组显隐);
- **轨迹:全部锤**;调色板按杆序插值(A: 橙→蓝,B: 绿→紫),N=2 时与现状一致;摆杆颜色保持单色;
- **实时数据面板**动态生成 θ_i/ω_i 行 + 能量/时间(缓存 span 引用,避免逐帧 getElementById);
- **对比模式**:施加变量下拉按杆数×模式生成(θ_i/φ_i/ω_i/ωφ_i);resync 按字段名解析杆序号;
- index.html 固定滑条替换为动态容器;styles 增加卡片网格样式。

## 5. 验证

**validate_physics.mjs(平面,数组状态)**:
1. 平衡态 N=3(全 0 与全 π):导数幅值 < 1e-12;
2. 逐点 dE/dt 相容 N=3:< 1e-5;
3. N=2 回归:混沌 60s、dt=0.0005,漂移 < 1e-6(与旧专用方程同性质);
4. N=3 守恒:同上 < 1e-6;
5. 小角度周期:N=2、m₂=1e-3(L₂≠0 保证 M 可逆),周期 ≈ 2π√(L₁/g) < 2%。

**validate_spherical.mjs(球面,数组状态)**:
1. 平衡态 N=3;2. 约束残差 N=3 60s(dt=0.002)< 1e-9;3. 能量守恒 N=3 60s(dt=0.0005)< 1e-6;4. N=2 回归(约束+守恒);5. 平面极限周期 N=2;6. 非平面性 N=2。
