# 混沌双摆模拟网页开发计划

## 项目概述
创建一个交互式网页，模拟**混沌双摆（Double Pendulum）**的运动。混沌双摆是由一个摆连接另一个摆组成的物理系统，是经典的混沌系统，对初始条件极其敏感。

## 物理原理
双摆系统由两个质点和两根无质量刚性杆组成：
- 上摆：质量 m₁，杆长 L₁，角度 θ₁
- 下摆：质量 m₂，杆长 L₂，角度 θ₂

**拉格朗日方程**（无解析解，必须数值求解）：
```
d²θ₁/dt² = f(θ₁, θ₂, dθ₁/dt, dθ₂/dt, m₁, m₂, L₁, L₂, g)
d²θ₂/dt² = f(θ₁, θ₂, dθ₁/dt, dθ₂/dt, m₁, m₂, L₁, L₂, g)
```

**特性**：
- 对初始条件极其敏感（蝴蝶效应）
- 不可预测的混沌运动
- 能量守恒（无阻尼情况）

## 技术方案
- **前端框架**: 纯 HTML + CSS + JavaScript（无需构建工具）
- **图形渲染**: Three.js（WebGL）ES Modules
- **物理模拟**: Runge-Kutta 4阶数值积分（RK4）
- **Three.js 引入**: importmap + CDN

## 功能模块

### 1. 物理引擎模块
- 双摆运动方程（拉格朗日方程）
- RK4 数值积分求解
- 支持可调参数：
  - 上摆质量 m₁、杆长 L₁
  - 下摆质量 m₂、杆长 L₂
  - 初始角度 θ₁₀、θ₂₀
  - 初始角速度 ω₁₀、ω₂₀
- 实时计算总能量（验证守恒）

### 2. Three.js 3D 可视化模块
- 3D 场景搭建
- 双摆几何体：
  - 固定支点
  - 上摆杆 + 质点（球体）
  - 下摆杆 + 质点（球体）
- 轨迹线显示（下摆质点轨迹）
- OrbitControls 轨道控制器

### 3. 交互控制模块
- 参数调节面板
- 播放/暂停/重置按钮
- 轨迹显示开关
- 实时数据显示（角度、角速度、能量）
